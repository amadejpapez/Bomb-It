## ✨ Features

- there is grid of boxes with numbers
- a user can move this boxes around
- if the number on the two boxes is the same they will be merged into a bigger number box
- do this until the number on the box is 2048!

<br>

## 💻 Technical details

- Desktop only
- written in libGDX
